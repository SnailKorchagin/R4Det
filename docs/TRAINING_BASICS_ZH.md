# 专题一：深度学习训练基础

[返回学习总览](LEARNING_OVERVIEW_ZH.md) · [下一专题：配置与数据流](CONFIG_AND_DATA_ZH.md)

先把复杂模型当成一个函数：输入雷达点云和图像，输出目标类别及 3D 框。这个函数内部有大量可调整的数值，称为**模型参数**。训练就是利用有正确答案的数据，反复调整这些数值。

## 1. 六个最重要的词

| 词 | 本项目中的意思 |
|---|---|
| 样本 | 一次雷达、相机观测以及几何信息；当前时序实现还会打包前帧 |
| 标注 / GT | 人工或数据集给出的正确类别、2D/3D 框等，用于训练和评估 |
| 模型参数 | 卷积核、线性层权重、bias 等随训练改变的数值 |
| 超参数 | 人指定的训练设置，如学习率、batch size、epoch 数 |
| loss | 衡量预测与标注差异的数值，模型可有多项 loss |
| checkpoint | 保存模型状态的 `.pth` 文件，可能还包含优化器状态、进度和配置元信息 |

例如 `lr=0.0002` 是超参数。某个卷积核里的 `0.0137` 是模型参数。训练通常改变后者，不会自动改写前者。

## 2. 一次迭代如何工作

用简化伪代码表示：

```python
batch = next(data_loader)          # 取一批经过预处理的样本
losses = model.forward_train(**batch)
loss = sum_trainable_losses(losses) # 框架汇总可训练的 loss
optimizer.zero_grad()              # 清掉上次迭代的梯度
loss.backward()                    # 计算参数对 loss 的梯度
optimizer.step()                   # 按梯度更新可训练参数
```

这是帮助理解的流程，并非本仓库逐字源码。实际项目由 OpenMMLab 的训练框架调度，可能还有梯度裁剪、分布式同步和 hook。

**前向传播**：模型拿当前参数计算预测。**反向传播**：根据 loss 计算每个可训练参数对错误的影响。**优化器**：按照梯度和学习率决定本次更新幅度。下一批数据会使用更新后的参数。

## 3. batch、iteration、epoch

- **batch**：一次送入模型的一组样本。当前配置 `samples_per_gpu=4`，即每张 GPU 的数据加载批量为 4。
- **iteration / iter**：处理一个 batch 并完成一次参数更新，通常称一次迭代。
- **epoch**：按数据加载器的采样方式走完一轮训练数据。当前 `RepeatDataset(times=2)` 使逻辑数据集长度加倍；实际迭代次数还受 GPU 数、sampler 和丢弃尾批等设置影响。

当前配置 `runner.max_epochs=18`。文件名中含 `12e`，但最终训练轮数由配置和命令行覆盖后的 `runner.max_epochs` 决定。

## 4. 为什么训练与推理都需要 R4Det.py

同一个模型结构有两种使用方式：

```text
训练：输入 + 标注 → 预测 + loss → 更新参数
推理：输入 + 已训练参数 → 预测结果
```

[R4Det.py](../mmdet3d/models/detectors/R4Det.py) 实现共享的特征提取，也实现 `forward_train()` 和 `simple_test()`。推理通常不计算梯度，也不更新参数。网络结构由配置和模型代码重建，学到的数值由 checkpoint 加载。

## 5. 损失不等于检测指标

训练用 loss 指导参数更新；验证用检测指标评价结果，例如 AP。loss 下降不保证 AP 每次都升高。因此配置既指定训练损失及其权重，也指定验证频率。当前配置 `evaluation.interval=1`、`checkpoint_config.interval=1`，意图是每轮评估和保存一次。

## 6. 冻结参数是什么意思

`freeze_images=True` 会调用模型里的冻结图像分支逻辑，使相关参数不参与更新。冻结与否应查看 [R4Det 实现](../mmdet3d/models/detectors/R4Det.py) 中 `freeze_img_model()` 的实际范围，不能仅凭变量名断言整个模型都冻结。训练时只有允许求梯度并交给优化器的参数会被更新。

## 7. 一个最小的理解练习

假设模型预测某个物体属于 Car 的概率偏低，框位置也偏远：

1. 模型输出类别分数和框。
2. 分类 loss、框回归 loss 根据标注给出误差。
3. 反向传播求梯度。
4. 优化器改动能影响这些预测的参数。
5. 下次遇到相似输入时，预测可能更接近标注。

真正的 R4Det 还有深度、前景、BEV 等辅助 loss。先掌握这个闭环，再研究每项 loss 的公式。
