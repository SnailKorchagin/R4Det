# 02 图像特征与雷达辅助深度：像素如何获得米制位置

[主要概览](../LEARNING_OVERVIEW_ZH.md) · [上一篇：点云与 Pillar](01_POINTS_PILLAR_BEV_ZH.md) · [下一篇：投影与融合](03_PROJECTION_FUSION_ZH.md)

本篇从针孔相机几何出发，解释 FPN、深度概率和稀疏雷达约束。输出是像素 context 特征与深度分布，下一篇再把它们送进 BEV。

## 1. 一个像素为什么不能直接放进 BEV

忽略畸变并使用相机坐标系时，投影关系是

$$u=f_xX_c/Z_c+c_x,\qquad v=f_yY_c/Z_c+c_y.$$

给定 $(u,v)$，只能得到一条射线：

$$\mathbf X_c(d)=dK^{-1}[u,v,1]^\top.$$

这里 $d$ 是相机光轴深度 $Z_c$，不应直接替换成雷达斜距 $\sqrt{x^2+y^2+z^2}$。例如 $f_x=800,c_x=320,u=400$，则 $X_c/Z_c=0.1$：10 m 深度对应横向 1 m，20 m 深度对应横向 2 m，像素位置完全相同。

雷达提供米制空间位置，经外参投影后能约束射线上的深度。但点只覆盖少量像素，还可能受遮挡、时间偏差和标定误差影响，因此需要学习稀疏测量与图像上下文如何共同确定深度。

## 2. ResNet/FPN 提供的是什么

[当前配置](../../configs/r4det/TJ4D-R4Det_det3d_2x4_12e.py) 使用 ResNet-50 与五层 FPN。浅层分辨率高、保留局部纹理；深层感受野大、表达更抽象的上下文。FPN 把不同尺度的信息组织成多尺度特征。

输入增强后为 `[B,3,480,640]`，采用 `to_rgb=False` 与 BGR 均值 `[103.530,116.280,123.675]`。不能把 RGB 的 0～1 输入直接替代这一预处理。

[R4Det.extract_feat](../../mmdet3d/models/detectors/R4Det.py) 将五层 FPN 特征插值到 `60×80` 后拼接，成为 `[B,1280,60,80]`。这里 $1280=5\times256$；这些通道是图像描述，不是 1280 个深度层。

## 3. 为什么预测分布而不只预测一个数

设深度 logits 为 $a_k$，softmax 给出

$$p_k=\frac{\exp(a_k)}{\sum_j\exp(a_j)},\qquad \sum_kp_k=1.$$

当前 `dbound=[1,73,1]` 对应 72 个离散深度取值。输出 `[B,72,60,80]`，context 则为 `[B,1,256,60,80]`。单相机轴和深度轴是不同的轴。

源码还计算期望深度 $\hat d=\sum_kp_kd_k$。若 10 m 和 20 m 各占 0.5，期望为 15 m，却没有任何概率质量放在 15 m。LSS 使用完整分布可以保留这种多峰不确定性；只画期望深度图会隐藏它。

1 m 深度间隔限制离散表达方式，但不能推出最终框误差恰好 1 m。分类概率也并非天然校准的真实不确定度：网络可能自信地预测错误深度。

## 4. 当前 GeometryDepth_Net 的实际计算

[GeometryDepth_Net.forward](../../mmdet3d/models/img2bev/forward_projection/GeometryDepth_Net.py) 先把图像特征和相机几何编码交给内部 depth net，拆出单目深度 logits 与 context，然后进行条件融合：

```text
多尺度图像特征 + 相机几何编码
  → 单目深度 logits → softmax → mono_volume
雷达投影深度 → 下采样/离散化 → 深度体编码 → softmax
  → 与 mono_volume 聚合 → softmax → 最终 depth_volume
另有 use_extra_depth 条件分支，可再融合 extra_depth
```

当前配置启用 `use_radar_depth=True`，而 `use_extra_depth=False`，所以此配置不会执行额外深度融合分支。雷达深度并不是把每个有点像素的预测强制设成真值，而是进入可学习的深度体融合。需要对照实际开关判断 extra depth 是否参与，不能因为函数接收了参数就认定分支必然执行。

这里区分三种“深度”：雷达投影测量、网络预测分布、训练深度监督。它们来源不同。推理数据合同的审计还应检查 `depth_comple/gt_depths` 等字段最终在哪里使用，不能把全部带 depth 的变量都叫网络预测。

## 5. 性质、误差与检查方式

| 改变条件 | 可能出现的现象 | 应检查什么 |
|---|---|---|
| 雷达点减少 | 米制约束变弱，更多依靠图像先验 | 分距离的深度误差与有效点数量 |
| 外参有偏差 | 雷达深度约束落到错误物体上 | 原图上投影叠加与遮挡关系 |
| 图像缩放但内参/增强矩阵未同步 | 整体投影位置错位 | 增强前后同一点坐标 |
| 深度多峰 | 期望落在两个表面之间 | 完整概率曲线，而非只看均值 |
